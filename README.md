# Grandma vs. AI — The Heritage Challenge
### اليدّة ضد الذكاء الاصطناعي — تحدي التراث

An interactive, fully Arabic-voiced storytelling game (about 5 minutes) made for the **UAE Year of Family 2026**.
ROBO 2050, a know-it-all robot, challenges Grandma Noor. Two sisters help ROBO learn that technology can preserve knowledge, but families give traditions their meaning.

**Play:** open `index.html` in a browser (or the GitHub Pages link for this repository). Best on a laptop or tablet, or a phone held sideways.

## What's inside
- Four challenges: the Majlis (hospitality), the Dallah (generosity), the Ghaf tree (nature), Family Stories (memories)
- Arabic voice-over for every line, with Arabic and English subtitles
- ROBO's transformation into a Heritage Guardian and a personalised certificate

## Files
- `index.html` — the whole game (art, music and logic)
- `audio/` — voice lines (`g*` Grandma, `r*` ROBO, `s1*` older sister, `s2*` younger sister, `n*`/`q*` narrator)
- `lines.js` — the script: every line in Arabic and English

To use your own recordings, replace the matching file in `audio/` with an MP3 of the same name.
